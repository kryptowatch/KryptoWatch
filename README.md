# KryptoWatch

Building open-source resources for the crypto and Web3 ecosystem.

KryptoWatch aims to make it easier to research crypto services, compare options, and build with reliable public information.

## Focus areas

- **Exchange discovery** — directories that help people compare centralized exchanges using clear, verifiable criteria.
- **Crypto swaps** — structured information about swap services, supported networks, and service features.
- **Security** — practical wallet safety guidance, threat awareness, and tools for safer crypto use.
- **Developer APIs** — a curated directory of APIs for market data, exchanges, and blockchain infrastructure.

These resources are being developed as separate public projects. Listings and guidance should link to authoritative sources, distinguish facts from estimates, and be reviewed regularly because crypto services and policies change.

## Contribute

Useful contributions include correcting outdated information, adding primary-source references, improving documentation, and reporting security or accessibility issues. Please keep submissions factual and disclose affiliations or conflicts of interest.
